# Akeem's Timetable Generator - PWA

Ready for GitHub Pages and PWA Builder.

## Files
- index.html, manifest.json, sw.js
- icons/ (72-512px + maskable)

## Steps
1. Create GitHub repo
2. Upload all files (keep icons folder)
3. Settings > Pages > Deploy from branch main/root
4. Copy Pages URL to https://www.pwabuilder.com/ > Build My PWA > Android/Windows/iOS

Test offline support via Chrome DevTools > Application > Service Workers.
